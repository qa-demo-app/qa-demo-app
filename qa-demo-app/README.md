# QA Automation Practice Website

Practice site for **Playwright, Selenium and API testing**: login, register, products, cart and checkout, forms, tables, alerts, iframes, windows/tabs, file upload, drag and drop, mouse and keyboard, API playground, network testing, authentication, WebSocket and error pages.

- **Live site:** https://qa-demo-app.github.io/qa-demo-app/
- Served from `index.html` (served by GitHub Pages). API, sessions and WebSocket are simulated in the browser.
- **Full project** (React + TypeScript, Express API, Swagger, Playwright tests, Docker, GitHub Actions): see the `project/` folder and `project/README.md`.
